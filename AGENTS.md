# Контекст проекта

- LLM Console — консольное приложение на Go (модуль `llm-console`, go.mod: Go 1.22).
- Используется OpenAI-совместимый HTTP API; основной провайдер — DeepSeek.
- Общение и документация проекта — на русском.
- Настройки читаются из `config.json`, другой файл выбирается через `--config`.
  Ключи API не добавлять в Git и не выводить при проверках.

## Архитектура

- `cmd/llm-console/main.go` — загрузка конфигурации, сборка зависимостей и запуск чата.
- `cmd/llm-console/args.go` — параметры запуска и справка.
- `cmd/llm-console/console.go` — интерактивный ввод и оформление вывода.
- `internal/app/ChatService` — сценарий диалога и контекст в памяти; не зависит от UI.
- `internal/llm` — контракт клиента, модели сообщений и OpenAI-совместимый транспорт.
- `internal/tools` — инструменты `current_time`, `calculate`, `text_length`.
- `internal/config` — загрузка конфигурации.

## Правила разработки

- **Тесты не пишем:** не добавлять новые тесты и не расширять существующие,
  если пользователь явно не изменит это правило.
- Существующие тесты не удалять без отдельного запроса.
- Для проверки изменений использовать форматирование, сборку и при необходимости
  ручную проверку. Не обращаться к платному API без необходимости.
- Не записывать в документацию и ответы персональные абсолютные пути и сведения
  о локальном расположении SDK. Для файлов проекта использовать относительные пути.
